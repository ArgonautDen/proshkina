# Дизайн-референс проекта

Источник: `~/Documents/GitHub/vet-remote-commercials` (React/Vite-версия).
Задача: перенести палитру, ощущение "воздушности", кнопки и анимации на новый
проект сайта ветеринарного врача с онлайн-консультациями.

## Стек

- **Next.js** (решено, 2026-09-21) — вместо Vite/React Router из референса.
  Tailwind + анимации переносим на новый стек концептуально, а не копируем
  конфиг 1:1 (роутинг/структура файлов будут next-овские).

## Форма и тени

- Радиусы: xl=18px, 2xl=22px, 3xl=28px — всё скруглённое, мягкое
- Тени (многослойные, синий+оранжевый оттенки):
  - `soft`: `0 8px 32px rgba(44,74,110,.12)`
  - `card`: `0 16px 48px rgba(44,74,110,.18), 0 2px 8px rgba(0,0,0,.06)`
  - `lift`: `0 24px 60px -12px rgba(44,74,110,.28), 0 10px 26px -6px rgba(200,101,42,.18)`
  - `glow`: `0 0 0 1px rgba(200,101,42,.18), 0 20px 50px -12px rgba(200,101,42,.4)`
- Фоновые градиенты:
  - `mesh-hero` — 3 радиальных пятна (indigo слева-сверху, pumpkin справа-сверху,
    indigo справа-снизу), лёгкие, полупрозрачные — создают "воздушность" на hero
  - `cta-gradient`: `linear-gradient(135deg, #c8652a 0%, #e8854a 100%)`

## Кнопки

- **primary**: `cta-gradient` фон, белый текст, `shadow-card` → hover
  `shadow-lift` + `-translate-y-0.5` (лёгкий подъём)
- **secondary**: белый фон, indigo-700 текст, ink-200 рамка → hover рамка
  indigo-300
- **outline**: прозрачный, белая рамка 40% — для тёмных фонов
- **ghost**: прозрачный, ink-600 текст → hover indigo-700
- Радиус кнопок: xl (18px), высота md=44px/lg=56px
- **Shimmer-эффект**: медленный диагональный блик (`shimmer-sweep`, 9s), у
  каждой кнопки свой случайный `animation-delay` (0 до -9s), чтобы несколько
  shimmer-кнопок на странице не мигали синхронно

## Анимации

- **Reveal on scroll**: fade+slide (up/left/right, смещение 24-48px),
  spring-физика (stiffness 90, damping 20, mass 0.8), срабатывает при каждом
  входе в viewport (не только once) — "живое" ощущение
- **float**: медленное вертикальное дыхание декоративных блобов, 6s ease-in-out
  infinite, translateY(-10px)
- **brand-ring-float**: декоративные полупрозрачные круги на hero, 15-20s,
  translate+rotate, разное направление (normal/reverse)
- **glass-shine-card**: матовое стекло — `backdrop-filter: blur(18px)
  saturate(140%)`, полупрозрачный белый фон с градиентом, тонкая точечная
  текстура (шум), hover = медленный подъём тени (`transition-shadow
  duration-700`), НЕ подъём/масштаб — только тень
- **FAQ flip-card**: 3D-флип по клику (perspective 1600px, rotateY(180deg),
  cubic-bezier(0.19,1,0.22,1), 0.7s) — только на desktop/tablet, на мобильном
  обычный аккордеон
- Везде уважение `prefers-reduced-motion: reduce` (анимации схлопываются до
  0.001ms)

## Иконки

- Библиотека: **lucide-react** — единственный источник иконок в референсе,
  никакого отдельного кастомного SVG-набора (кроме логотипа)
- Паттерн "icon badge": контейнер `size-10`/`size-12`, `rounded-xl`, мягкий
  цветной фон (`bg-indigo-50` / `bg-pumpkin-50` / тематический типа
  `bg-rose-50` для "проблемных" пунктов) + сама иконка `size-5`/`size-6`,
  цвет текста в тон фону (`text-indigo-700`, `text-pumpkin-600`), обводочный
  line-style, `aria-hidden="true"` (декоративные, смысл несёт текст рядом)
- Для вет-тематики Lucide покрывает нужный набор без доп. зависимостей:
  `Stethoscope`, `Syringe`, `Heart`, `PawPrint`, `Calendar`, `Video`,
  `MessageCircle`, `ShieldCheck`, `Clock`, `Phone`, `CalendarCheck` и т.п.
- **Эмодзи не используются нигде в проекте** (решено, 2026-09-21) — ни в UI,
  ни в контенте/тексте. Везде, где нужен визуальный акцент/значок — только
  иконки Lucide по паттерну выше.

## Хэдер (решено, 2026-09-21)

- **Лого**: `vet-remote-commercials/src/assets/logo.png` (кот+собака+wifi-дуги +
  текст "VetRemote") используется как есть, с текстом — Дарья реальный
  пользователь сервиса VetRemote, имеет право на использование логотипа.
  На светлом хэдере лого (белое/прозрачное) кладётся на круглую подложку
  фирменного indigo (indigo-600/700). Клик по лого → `/booking` (та же
  заглушка, что и у CTA-кнопки hero).
- **Хэдер светлый, sticky** — прилипает сверху при скролле, самый базовый
  вариант (без hide-on-scroll-down, без уменьшения высоты).
- **Навигация справа** — 4 пункта:
  - «Обо мне» → якорь `#about` на главной
  - «Квалификация» → **отдельная страница** `/qualifications` (не якорь)
  - «Лекторская деятельность» → якорь `#lecturing` на главной
  - «Контакты» → якорь `#contacts` на главной
- **Активный якорь**: индикатор-точка рядом/под пунктом меню показывает, в
  каком блоке страницы сейчас находится скролл (через `IntersectionObserver`
  по секциям).
- **Мобильное меню**: круглая кнопка-гамбургер (иконка Lucide `Menu`),
  открывает меню.
- **Hover-эффект (везде в UI, не только хэдер)**: минималистичный —
  появление чёрного кружка (полупрозрачный/полный чёрный circle) за
  элементом при наведении. Использовать как общий паттерн интерактивных
  элементов (пункты меню, бургер-кнопка и т.п.), а не только для хэдера.
